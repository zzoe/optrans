# optrans — Optical Transfer

基于 QR-like 视觉编码的高速文件传输工具。发送端将文件编码为全屏灰度帧，接收端截屏解码还原文件。

## 快速开始

```powershell
# win7构建
cargo +nightly build --release --target x86_64-win7-windows-msvc -Z build-std

# win8+构建
cargo build -r

# 发送文件
optrans send ./file.bin

# 接收文件（输出路径可选）
optrans receive [./output.bin]
```

## 命令行参数

| 子命令    | 参数       | 说明                                             |
| --------- | ---------- | ------------------------------------------------ |
| `send`    | `path`     | 待发送的文件路径                                 |
| `receive` | `[output]` | 输出文件路径（可选，不指定时从发送端元数据解析） |

所有调优参数均为程序内部常量，可在 `src/common/constants.rs` 中调整。

## 架构

```
┌──────────────────────────────────────────────────────────────┐
│                         Sender                               │
│  file → read_file → FEC encode → Frame build → render → win  │
│                           │                                  │
│                           ▼                                  │
│                    渲染线程(异步)                            │
│                    channel(容量2)                            │
│                           │                                  │
│                           ▼                                  │
│                    显示循环(串行)                            │
│                    每帧 interval_ms                          │
└──────────────────────────────────────────────────────────────┘
                              │
                         屏幕光学通路
                              │
┌──────────────────────────────────────────────────────────────┐
│                         Receiver                             │
│                                                              │
│  capture线程 ──tx──→ aggregator线程                          │
│      │ spawn               │                                 │
│      └→ decode线程         │                                 │
│          做完 drop tx      │                                 │
│                            │                                 │
│  FrameCollector            │                                 │
│   seen_seqs去重            │                                 │
│   block→buffer             │                                 │
│   EOT→flush→写文件         │                                 │
└──────────────────────────────────────────────────────────────┘
```

### 发送端流程

1. **文件读取与分块**：`read_file_with_block_size()` 读取文件、计算 SHA-256、按帧容量分块
2. **块级 FEC 编码**：每组 128 个数据块 + 64 个校验块（容错 33%）
3. **帧构建**：组装元数据帧、数据帧（支持多块合并）、FEC 校验帧、EOT 帧
4. **灰度渲染**：将帧渲染为 RGBA 像素缓冲区（含 Finder Pattern、格式信息、数据矩阵）
5. **异步渲染 + 串行显示**：渲染线程通过有界 channel 发送像素，显示循环严格串行输出

### 接收端流程

1. **截屏捕获**：全速全屏截屏
2. **帧定位**：通过三个 Finder Pattern 定位帧角，支持长方形帧
3. **格式信息解码**：快速提取帧类型、序号、块索引等信息做去重预判
4. **并行解码**：新帧 spawn decode 线程处理 payload
5. **聚合重组**：aggregator 线程去重排序、FEC 恢复、SHA-256 校验、写文件

## 帧格式

```
┌────────────────────────────┐
│  Finder Patterns (3×7×7)   │
│  TL ──────────────── TR    │
│  │                         │
│  Format Info (顶2行)       │  ← CRC16 + 多数投票
│  │                         │
│  Data Modules              │  ← RS(255,217) + 灰度编码
│  │                         │
│  BL                        │
└────────────────────────────┘
```

### 帧类型（FrameType）

| 类型        | 值  | 说明                                              |
| ----------- | --- | ------------------------------------------------- |
| `Meta`      | 0   | 元数据帧：文件名、大小、SHA-256、总块数、FEC 参数 |
| `Data`      | 1   | 数据帧：文件数据块（支持多块合并）                |
| `EOT`       | 2   | 传输结束帧：空载荷，表示发送完成                  |
| `FecParity` | 3   | FEC 校验帧：块级 RS 纠删码的校验分片              |

### 格式信息（FormatInfo）

104 bits（13 bytes），含 CRC16 后共 15 bytes：

| 字段                | 位数 | 说明                                                                    |
| ------------------- | ---- | ----------------------------------------------------------------------- |
| `frame_type`        | 2    | 帧类型                                                                  |
| `frame_sequence`    | 16   | 帧序号，从 0 递增，用于去重                                             |
| `block_index`       | 32   | 数据块索引（FecParity 帧：高 16 位 = group_idx，低 16 位 = parity_idx） |
| `total_blocks`      | 32   | 总数据块数（仅元数据帧有效）                                            |
| `payload_bytes`     | 21   | 载荷字节数（最大 2,097,151）                                            |
| `encoding_mode_bit` | 1    | 编码模式：0=二值，1=灰度                                                |

### 元数据帧载荷格式

| 字段             | 长度 | 说明                     |
| ---------------- | ---- | ------------------------ |
| `name_len`       | 1B   | 文件名长度               |
| `file_name`      | N B  | 文件名（UTF-8）          |
| `file_size`      | 8B   | 文件大小（LE）           |
| `sha256`         | 32B  | 文件哈希值               |
| `total_blocks`   | 4B   | 总数据块数（LE）         |
| `fec_k`          | 2B   | FEC 每组数据分片数（LE） |
| `fec_m`          | 2B   | FEC 每组校验分片数（LE） |
| `fec_groups`     | 4B   | FEC 组数（LE）           |
| `fec_shard_size` | 4B   | FEC 分片字节长度（LE）   |

### 数据帧载荷格式（多块合并）

| 字段             | 长度   | 说明           |
| ---------------- | ------ | -------------- |
| `count`          | 2B     | 块数量（LE）   |
| `block_index[N]` | 4B × N | 块索引（LE）   |
| `data_len[N]`    | 4B × N | 数据长度（LE） |
| `data[N]`        | 变长   | 块数据         |

## 技术特性

### RS(255,217) 帧内纠错

- 每帧数据经过 RS(255,217) 编码
- 217 个数据码字 + 38 个校验码字
- 可纠正单帧内最多 19 个字节错误（捕获噪声）

### 块级 FEC（前向纠错）

- RS(192,128) 纠删码：每组 128 个数据分片 + 64 个校验分片
- 容错率 33%，接收端收到任意 128 个分片即可恢复该组全部数据
- 应对远程桌面（Horizon/Citrix）协议层丢帧

### 灰度编码

| 灰度级数 | Bits/Module | 说明                        |
| -------- | ----------- | --------------------------- |
| 2        | 1           | 二值模式（黑/白）           |
| 4        | 2           | 4 级灰度                    |
| 8        | 3           | 8 级灰度                    |
| 16       | 4           | 16 级灰度（默认，最高密度） |

灰度值采用等间距分布，解码阈值为相邻灰度值的中点。

### 心跳机制

帧右下角注入 2×2 像素的心跳块，帧序号决定灰度值循环（基准 128 ± 1），用于接收端同步检测。

主要常量位于 `src/common/constants.rs`：

| 常量                       | 默认值 | 说明                           |
| -------------------------- | ------ | ------------------------------ |
| `MODULE_PIXELS_DEFAULT`    | 4      | 每模块像素数（2-8，偶数）      |

| `GRAY_LEVELS_DEFAULT`      | 16     | 灰度级数                       |
| `FRAME_MARGIN_PX_DEFAULT`  | 20     | 帧边距像素（远程桌面建议 120） |
| `FEC_DATA_SHARDS`          | 128    | FEC 每组数据分片数             |
| `FEC_PARITY_SHARDS`        | 64     | FEC 每组校验分片数             |

## 技术栈

- Rust（纯 std，无异步运行时）
- RS(255,217) 纠错码（reed-solomon crate）
- Win32 GDI 全屏窗口 / 截屏
- 多线程流水线架构
- SHA-256 文件完整性校验
- CRC-16/XMODEM 格式信息校验
